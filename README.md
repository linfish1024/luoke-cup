**为洛可同学定制的世界杯预测游戏** ⚽

## 🎮 三种玩法

1. **🎯 预测模式** — 12 组选冠军/亚军 + 选总冠军
2. **⚽ 模拟整届** — AI 根据 ELO 评分跑完整赛程（48→32→冠军）
3. **⚔️ PK 对战** — 2-4 人轮流预测，看谁最准
